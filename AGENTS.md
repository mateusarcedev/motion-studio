# Instruções para agentes

Leia [`docs/WORKFLOW.md`](docs/WORKFLOW.md) antes de alterar o repositório. Todo trabalho do Motion Studio deve acontecer diretamente em `main`, sem branches auxiliares ou worktrees. Preserve alterações locais e arquivos não rastreados, faça commits atômicos, atualize documentação versionada e execute os quality gates antes de enviar ao remoto.

As instruções criativas deste projeto permanecem em [`CLAUDE.md`](CLAUDE.md); estas regras de Git e continuidade valem para todos os agentes.
