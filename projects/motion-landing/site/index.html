    instalação & uso

    CLI

    Instale, use, estude e adapte.

    Sem assinaturas, planos ou lock-in comercial. Pacotes npm modulares e abertos para rodar em qualquer projeto ou agente de IA.

    ℹ️ Pacotes npm em Release Candidate (v1.0.0-rc.1) — instalação pública direta disponível após a publicação oficial no registro.
    # 1. Instalar pacotes abertos (disponível publicamente após release npm)
    npm install -D motion-cli motion-core motion-studio-skills
    # 2. Inicializar estúdio com perfil seletivo de skills (core, web, motion, social, 3d, all)
    npx motion init --brand="MinhaMarca" --profile=core
    # 3. Diagnóstico e criação de entregáveis reais a partir de código
    npx motion doctor && npx motion create carousel post-lancamento

    pipeline

    08

    Um pipeline que se deixa auditar.

    Nada de código antes do storyboard. Você aprova o briefing e a direção de arte. O crítico nunca é o mesmo contexto que criou a peça.

    01

    Briefing

    Mensagem, público, duração, formatos e história.

    você aprova
    02

    Direção de arte

    Tipografia, cor, composição, movimento — e uma lista explícita do que evitar.

    você aprova
    03

    Storyboard

    Cena a cena, com tempos e números de frame.

    04

    Composição

    Código dirigido por frame ou slide em HTML/CSS. Zero aleatoriedade.

    05

    Render

    Stills primeiro e contact sheet; render completo só depois.

    06

    Crítico

    Contexto novo, avalia só o render. Defeitos com frame e evidência.

    aprovação
    07

    Reparo

    Menor correção possível, só nos frames afetados. Máximo de 2 rodadas por defeito.

    08

    Entrega

    Arquivos finais, pôsteres, contact sheets e o código-fonte que re-renderiza tudo.

    princípios

    03

    Frame N é sempre igual

    Tudo é guiado por número de frame ou tempo determinístico. Sem relógio, sem aleatório: o filme se reproduz bit a bit.

    Nada de UI inventada

    Só assets aprovados do produto. Se falta uma tela essencial, o estúdio pede — não desenha uma falsa.

    Movimento com propósito

    Se a animação não comunica nada, é decoração — e sai. A história precisa ficar legível em 4 stills.
