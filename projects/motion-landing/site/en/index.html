    Install, run, study and adapt.

    No subscriptions, pricing plans or commercial lock-in. Modular open-source npm packages to run inside your projects or with AI agents.

    ℹ️ NPM packages in Release Candidate (v1.0.0-rc.2) — direct public installation available upon official registry publication.
    # 1. Install open packages (publicly available upon npm release)
    npm install -D motion-cli motion-core motion-studio-skills
    # 2. Initialize studio with selective skill profile (core, web, motion, social, 3d, interactive, all)
    npx motion init --brand="MinhaMarca" --profile=core
    # 3. Environment diagnosis and real code-driven deliverable scaffolding
    npx motion doctor && npx motion create carousel post-lancamento

    03pipeline08

    A pipeline that lets you audit it.

    No code before the storyboard. You approve the brief and the art direction. The critic is never the same context that made the piece.

    01

    Brief

    Message, audience, duration, formats and story.

    you approve
    02

    Art direction

    Typography, color, composition, motion — and an explicit list of what to avoid.

    you approve
    03

    Storyboard

    Scene by scene, with timings and frame numbers.

    04

    Composition

    Frame-driven code or HTML/CSS slides. Zero randomness.

    05

    Render

    Stills and a contact sheet first; full render only after.

    06

    Critic

    Fresh context, reviews the render only. Defects with frame and evidence.

    sign-off
    07

    Repair

    Smallest possible fix, affected frames only. Max 2 rounds per defect.

    08

    Delivery

    Final files, posters, contact sheets and the source that re-renders everything.

    05

    principles

    03

    Frame N never changes

    Everything is driven by frame number or deterministic time. No wall clock, no randomness: the film reproduces bit for bit.

    No invented UI

    Only approved product assets. If an essential screen is missing, the studio asks for it — it never draws a fake.

    Motion with purpose

    If an animation communicates nothing it is decoration — and it goes. The story must read in 4 stills.
