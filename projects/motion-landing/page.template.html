    03

    Frame N é sempre igualFrame N never changes

    Tudo é guiado por número de frame ou tempo determinístico. Sem relógio, sem aleatório: o filme se reproduz bit a bit.Everything is driven by frame number or deterministic time. No wall clock, no randomness: the film reproduces bit for bit.

    Nada de UI inventadaNo invented UI

    Só assets aprovados do produto. Se falta uma tela essencial, o estúdio pede — não desenha uma falsa.Only approved product assets. If an essential screen is missing, the studio asks for it — it never draws a fake.

    Movimento com propósitoMotion with purpose

    Se a animação não comunica nada, é decoração — e sai. A história precisa ficar legível em 4 stills.If an animation communicates nothing it is decoration — and it goes. The story must read in 4 stills.
