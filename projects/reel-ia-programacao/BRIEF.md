## Mensagem

Dev que não usa IA está ficando para trás: IA já é realidade desde o ChatGPT (2022), as
ferramentas se multiplicaram, e usar IA desloca o foco do código para a regra de negócio e o
produto — que é o que o cliente quer (sistema funcionando, economia de dinheiro/tempo).

## Público e canal

Devs brasileiros; Instagram Reels / TikTok / Shorts, vertical 9:16, 1080×1920, 30 fps,
H.264 + AAC, −14 LUFS / true peak ≤ −1,5 dBTP.

## Duração

Ditada pela fala após os cortes (alvo: 55–62 s). Sem esticar nem acelerar a voz.

## Estrutura (história)

1. Abertura direta: "já é uma realidade, não temos para onde fugir" + card de tese.
2. Contexto: não é mais opcional desde 2022 (ChatGPT); vieram Antigravity, Codex, Claude Code.
3. Virada: "se você dev não está utilizando, você está ficando para trás" (ênfase visual).
4. Benefícios e mudança de foco: código → regra de negócio → produto.
5. Problema do dev (foco demais na tecnologia) × o que o cliente quer.
6. Fecho: economizar dinheiro, tempo, ou ambos.
