# @technomanceer/motion-studio

Instalador oficial do MOTION Studio.

```bash
npx @technomanceer/motion-studio init
```

Instala localmente (nunca global) o CLI, o Core e as 11 Skills oficiais, integra aos agentes
detectados (Claude Code, Codex, Gemini CLI, OpenCode, GitHub Copilot) e roda o diagnóstico dos motores.
É idempotente e não sobrescreve arquivos existentes. Todos os comandos do CLI também funcionam:
`npx @technomanceer/motion-studio doctor`.

Documentação completa: <https://github.com/mateusarcedev/motion-studio/blob/main/docs/INSTALLATION.md>
